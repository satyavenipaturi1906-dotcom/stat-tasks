### 1. Basic probability
Total = {1,2,3,4,5,6} = 6
Favourable less than 3 = {1,2} = 2
P = 2/6 = 1/3

### 2. Complement
Total = 15 + 10 = 25
Not DA = 10
P = 10/25 = 2/5

### 3. Addition rule
Odd = {1,3,5}, Greater than 4 = {5,6}
Union = {1,3,5,6} = 4
P = 4/6 = 2/3

### 4. Exactly one
Total = {HH, HT, TH, TT} = 4
Favourable = {HT, TH} = 2
P = 2/4 = 1/2
Successful sequences = *HT, TH*

### 5. At least one
P(at least one head) = 1 - P(No heads)
P(No heads) = P(TTTT) = $(1/2)^4 = 1/16$
P = 1 - 1/16 = 15/16

### 6. Overlapping card events
P(Queen) = 4/52, P(Spade) = 13/52, P(Queen and Spade) = 1/52
P = 4/52 + 13/52 - 1/52 = 16/52 = 4/13

### 7. Without replacement
1st King = 4/52
2nd King = 3/51
P = 4/52 \times 3/51 = 12/2652 = 1/221

### 8. Independent experiments
P(Tails) = 1/2
P(>4) = {5,6} = 2/6 = 1/3
P = 1/2 \times 1/3 = 1/6

### 9. Explain the relationship
Roll 1 and Roll 6 okesari ravu, so *Mutually Exclusive*.
P(1 \cap 6) = 0
Independent aithe $P(A \cap B) = P(A) \times P(B)$ undali.
P = 1/6 \times 1/6 = 1/36
0 \neq 1/36
So *Mutually Exclusive but Not Independent.*

### 10. Python extension
Total outcomes for 3 tosses = 8
Exactly two heads = {HHT, HTH, THH} = 3
Theoretical Probability:
P = 3/8 = 0.375
*Which condition changes?*
`count == 3` nunchi `count == 2` ki maruthundi.
import random
n = 100000
count = 0
for i in range(n):
    tosses = [random.choice(['H','T']) for _ in range(3)]
    if tosses.count('H') == 2:
        count += 1
print("Estimated:", count/n)
print("Theoretical:", 3/8)
